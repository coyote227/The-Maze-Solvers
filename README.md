# Maze Solver Comparison

A maze-generation and pathfinding comparison project built using **Python, C++, and Tkinter**. Compares four algorithms based on execution time and path length, with a GUI to visualize the results.

## Features

- Random maze generation using DFS.
- Maze visualization using Turtle graphics.
- Comparison of Dijkstra, BFS, DFS, and Linear Reachability Scan.
- Runtime and path-length comparison.
- Path visualization through a Tkinter GUI.

## Build and Run

Generate a new maze:

```powershell
python maze.py
